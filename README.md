# Salary Telegram Bot

Це Telegram-бот для розрахунку зарплати за кількість коробок.

## Як працює

- /start — початок нового запису
- бот запитує дату у форматі DD-MM-YYYY
- потім запитує кількість великих коробок
- потім кількість малих коробок
- дата зберігається в Excel разом з записом
- формула для розрахунку:
  - великі: (кількість × 0.90) / 2
  - малі: (кількість × 0.70) / 2
- дані зберігаються в Excel-файлі `data/YYYY-MM.xlsx`
- у файлі є загальний підсумок за місяць

## Встановлення

1. Встановіть залежності:

   ```bash
   pip install -r requirements.txt
   ```

2. Відкрий файл `config.py` і заміни токен:

   ```python
   BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
   ```

   на свій токен бота.

   Альтернативно можна встановити змінну середовища:

   Linux/macOS:

   ```bash
   export BOT_TOKEN="your_token_here"
   ```

   Windows PowerShell:

   ```powershell
   $env:BOT_TOKEN="your_token_here"
   ```

3. Запустіть бота:

   ```bash
   python salary_bot.py
   ```

## Команди

- /start — почати новий запис
- /total 2026-08 — показати загальну суму за місяць
- /cancel — скасувати поточний запис

## Формат Excel

Файл створюється у папці `data/`.

Колонки:

- Date
- Big boxes
- Big pay
- Small boxes
- Small pay
- Day total

Після кожного запису бот автоматично перераховує загальну суму за весь місяць.
